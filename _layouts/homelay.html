Our group is affiliated with the School of Computer Science and Technology @ Shandong University . We currently work in four areas:

  • LLM for Security: Vulnerability Discovery, Program Analysis, Automated Security Testing, Security Agents.
  • LLM Security: Jailbreak Attacks, Prompt Injection, Adversarial Attacks, Trustworthy LLM Applications.
  • Mobile Security: Android Security, Mobile Privacy, Vulnerability Detection, Security Measurement.
  • IoT & Embodied AI Security: IoT Security, Robot Security, Embodied AI Security, Physical Interaction Security.
